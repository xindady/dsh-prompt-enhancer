# dsh-prompt-enhancer

一个 DeepSeek Harness 插件：在输入框工具栏加一个 **✦** 按钮，点击即可把当前草稿改写成更清晰、更具体的提示词。

- 结果直接写回输入框，可撤回
- 草稿中的 `@文件引用` 逐字保留
- 输入框为空时不显示按钮

## 使用

1. 在输入框里写下你的提示词（为空则按钮不显示）
2. 点击工具栏右侧的 **✦** 图标
3. 稍等片刻，草稿会被替换为优化后的提示词
4. 不满意就点 **撤回**，恢复原文

按钮有三种状态：

| 状态 | 外观 | 说明 |
|---|---|---|
| 待优化 | ✦ | 点击开始优化 |
| 优化中 | 旋转图标 | 自动禁用，防止重复点击 |
| 可撤回 | ↺ 撤回 | 点击恢复原始提示词 |

优化完成后如果手动修改了草稿，撤回按钮会自动变回 ✦。

## 安装

**方式一：插件管理器（推荐）**

在对话中让 Agent 安装本目录，或使用插件管理工具：

```
plugin_manager { "action": "install_bundle", "target": "<本目录绝对路径>" }
```

安装后可在 **侧边栏 → 插件** 页看到「提示词增强」，可随时启停。

**方式二：手工挂载**

在 profile（`$DSH_HOME/profiles/<name>`）下：

1. 让包可被解析：`pnpm add link:<本目录绝对路径>`
2. 在 `cordis.patch.yml` 追加：

```yaml
- insert:
    - id: prompt-enhancer
      name: 'dsh-prompt-enhancer'
```

> 替换已安装的插件后需重启进程才能加载新代码。

## 要求

- Harness 已配置可用的模型服务
- 优化使用当前部署的默认模型，可在插件配置中指定 `provider` / `model` 覆盖
